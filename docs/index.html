aria

HTTP API service for downloading Apple Music tracks in AAC and Hi-Res Lossless ALAC (24-bit / 48 kHz). Built for speed, reliability, and integration.

ALAC 24-bit AAC 256k REST API

⚙ Architecture

Client (aria_lite.py / curl / any HTTP client) │ ├─ GET /download/<id>?fmt=alac │ ▼ aria server (Flask :8899) │ ├─ apple_api.py → Apple Music catalog API (metadata, HLS URLs) ├─ m3u8_select.py → Pick best ALAC variant from HLS master ├─ m4s_parser.py → Parse fragmented MP4, extract encrypted samples │ ├─ DecryptPool (round-robin N sidecar instances) │ ├─ sidecar :47010 → FairPlay sample-by-sample decrypt │ ├─ sidecar :47011 → (instance 2) │ └─ sidecar :47020 → HLS master URL resolution │ ├─ m4a_writer.py → Patch decrypted samples back into ALAC m4a │ ├─ Rename enca → alac in ALL stsd entries │ └─ Neutralize senc/saiz/saio → free boxes │ └─ Response: decrypted .m4a (tagged with metadata + cover art)

⚡ Quick Start

# 1. Install dependencies
pip install -r requirements.txt   # flask, httpx, m3u8, pywidevine, mutagen

# 2. Configure Apple Music credentials
mkdir -p ~/.config/aria
cat > ~/.config/aria/config.json <<'EOF'
{
  "accessToken": "eyJh...",
  "mediaUserToken": "0.AmW..."
}
EOF

# 3. Start sidecar (FairPlay decrypt service)
python3 aria_sidecar.py -F --instances 2

# 4. Start aria server
export API_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(24))')"
export ARIA_INSTANCES=2
python3 server.py --port 8899

# 5. Use it
curl -H "Authorization: Bearer $API_TOKEN" \
  "http://localhost:8899/download/1615585008?fmt=alac" -o song.m4a

🔍 ALAC Pipeline Deep Dive

How a single ALAC track goes from Apple's CDN to a playable .m4a file:

1
Resolve HLS Master

sidecar's m3u8 port (47020) resolves an Apple Music adamId to an enhanced-HLS master playlist URL. m3u8_select.py picks the highest quality ALAC variant (typically 48 kHz / 24-bit).

2
Download Encrypted Stream

The selected variant URL points to a single fragmented MP4 file (~50 MB for a 4-minute song). m4s_parser.py parses it into individual encrypted samples (typically 2000-3000 per track).

3
FairPlay Decrypt

aria_rpc.py sends each sample to sidecar over a pipelined TCP connection (port 47010). Writer and reader threads run concurrently — writer pushes ciphertext, reader collects plaintext. ~4 seconds for a full track.

4
Patch Container (m4a_writer)

The critical step. Three transformations turn the encrypted fragmented MP4 into a valid ALAC file:

a) Rename all enca sample entries to alac in stsd (not just the first — the original bug)

b) Remove sinf boxes (DRM metadata) from each entry

c) Overwrite senc/saiz/saio boxes in every traf with free (neutralize encryption flags)

5
Tag & Serve

Metadata (title, artist, album, cover art) is embedded via mutagen's MP4 atoms. The file is cached and served as a standard .m4a download.
