1. What is aria?

aria is a self-hosted service that downloads Apple Music tracks in lossless quality. Give it a song ID or album ID, and it returns a fully tagged .m4a file — with cover art, metadata, and bit-perfect audio.

It supports two quality tiers:

AAC 256k

Lossy, compact. Uses Widevine CDM + mp4decrypt. ~5 MB per track. Good for casual listening.

ALAC 24-bit / 48kHz

Lossless, Hi-Res. Uses FairPlay via sidecar. ~50 MB per track. Bit-for-bit identical to the studio master.

2. Audio Formats Explained

If you're new to lossless audio, here's what the terms mean:

FormatTypeBitrateQualityFile Size (4 min)
MP3 320kLossy320 kbpsGood~10 MB
AAC 256kLossy256 kbpsVery Good (better than MP3 at same rate)~8 MB
ALAC 16/44.1Lossless~900 kbpsCD Quality~27 MB
ALAC 24/48Lossless~2500 kbpsHi-Res (studio master)~50 MB
ALAC 24/192Lossless~9200 kbpsUltra Hi-Res~180 MB

ALAC (Apple Lossless Audio Codec) compresses audio without losing any data. When you decompress it, you get back the exact same samples the studio recorded. This is different from AAC/MP3, which permanently discard sounds your brain is less likely to notice (psychoacoustic masking).

Bit depth (16 vs 24) determines dynamic range — 24-bit can represent quieter details. Sample rate (44.1 vs 48 vs 192 kHz) determines the highest frequency that can be captured — 48kHz covers well beyond human hearing (20kHz).

3. How the Pipeline Works

When you request a track, aria goes through 9 steps to deliver a playable file:

1
You provide a song ID

e.g. python aria_lite.py 1615585008 --fmt alac

2
aria asks Apple for metadata

Calls the Apple Music catalog API to get the song's name, artist, album, artwork URL, and HLS playlist URL.

3
Apple returns an HLS master playlist

A .m3u8 file listing all available quality variants (AAC, ALAC at various sample rates).

4
aria picks the best variant

m3u8_select.py chooses the highest-quality ALAC stream (24-bit, up to 192kHz).

5
aria downloads the encrypted audio

The stream is a fragmented MP4 file (50+ MB) containing encrypted ALAC samples. Downloaded from Apple's CDN.

6
sidecar decrypts each sample

Samples are sent over TCP to the sidecar service, which decrypts them one by one using FairPlay. Pipelined for speed (15 MB/s).

7
aria repairs the container

m4a_writer.py patches the MP4: renames enca (encrypted) to alac in all sample descriptions, and neutralizes encryption metadata boxes.

8
aria writes metadata

Uses mutagen to embed title, artist, album, track number, cover art (1200x1200 JPEG) into the .m4a iTunes atoms.

9
You get a playable .m4a file

24-bit / 48kHz ALAC, fully tagged, ready for any player.

8. API Reference

All endpoints except / and /health require Authorization: Bearer TOKEN.

MethodEndpointDescription
GET/healthService health (no auth)
GET/search?q=term&type=songsSearch songs, albums, artists
GET/song/<id>Song metadata
GET/album/<id>Album + track list
GET/artist/<id>Artist + albums
GET/download/<id>?fmt=alacDownload (default AAC; ?fmt=alac for Hi-Res)
GET/album/<id>/downloadDownload album as ZIP
POST/batchBatch download: {"ids":[...],"fmt":"alac"}
